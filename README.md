🧠 Design Is My Debugger

When something doesn't feel right in an interface, I don't always look at the code first.

Sometimes the problem is:

unclear hierarchy

unnecessary complexity

weak spacing

poor visual direction

too much information

friction in the user journey

That's why my design background influences the way I write frontend code.

I don't just build what is designed.
I think about why it should be designed that way.

Not every project needs to become a product.

Sometimes I build something simply because I want to know:

“Can this be done better?”

That mindset takes me into:

UI Concepts · Frontend Interactions · Automation · AI Workflows · Design Systems · Creative Coding

🎯 What I Care About

01 — Clarity
If users need instructions to understand an interface, it probably needs more thought.

02 — Details
Typography, spacing, alignment, motion and tiny interactions matter.

03 — Simplicity
Remove unnecessary complexity before adding more features.

04 — Performance
A beautiful interface should still feel fast.

05 — People
Technology is the medium. People are the reason.
